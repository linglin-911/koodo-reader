# 批注界面与阅读交互需求

- 文档状态：产品设计阶段，记录截至 2026-11-09 已明确的需求与交互规则
- 适用项目：Koodo Reader Windows Electron 桌面版
- 对应分支：diagnostics/phase1-logging
- 范围：阅读界面三类批注的记录/查询/二次编辑、统一批注管理工作区、全局/局部标签作用域、局部标签管理、原文预览与阅读定位
- 非目标：本文件不代表相关界面已经实现，也不代表底层能力已经全部验收

本文根据用户讨论确认。若与旧界面或旧交互不同，以本文已确认规则为准。未确认事项单独列出，不得在实现时自行补成既定需求。

## 1. 产品目标与设计原则

软件主要用于阅读大型 TXT 小说，并围绕原文记录、整理和回看批注。核心使用需求是「记」与「查」：初读快速记、重读查看并偶尔修改、写作时通过批注找回原文。跨书籍引用、规律整理与写作工作区仅为未来设想，本阶段不实施。

阅读界面以阅读为中心，提供快速记录、当前章节批注查看、原文定位和必要的上下文参考；复杂、完整的批注检索和管理放在阅读界面之外的统一管理入口中。阅读界面不应演变成完整的批注管理器。

设计优先考虑 Windows 桌面鼠标与键盘操作、大型书籍和大量批注场景。列表和摘要按需加载，批注正文详情按需读取，不因打开面板而加载全书所有批注正文，也不为几千章创建大量常驻控件。

小说继续保存在 Koodo 原有书库中。不为批注功能另建小说项目文件夹、原文副本或第二套数据库。

## 2. 三类批注的业务规则

三类批注是独立实体。可以在界面上按书籍、章节或范围组织和展示，但展示分组不代表数据上的父子关系。

### 2.1 共同内容字段与分类规则

三类批注均只有以下用户内容：

- 正文：批注的主要内容。
- 标签：可选，用于标记主题或分类。

明确规则：

- 不设置用户可编辑的标题。批注没有标题，只有正文。
- 不设置独立的内部分类字段或分类控件。
- 标签是唯一的结构化分类方式，小批注、章节批注和大批注均可使用标签。
- 标签具有两种作用域：**全局标签**在所有书籍中可使用（如「人物描写」）；**局部标签**只在所属书籍中可使用（如某书人物「洛青」）。一条批注可以同时使用这两种标签。
- 统一批注管理工作区只负责当前所选书籍的**局部标签管理**，不提供全局标签管理入口；全局标签在何处维护尚未定稿。
- 标签作用域是标签的共享范围，不新增批注的「内部分类」字段。底层标签实体、身份与现有 JSON/备份的兼容设计须在实施前核对。
- 标签不是必填项。用户可以不添加标签。
- 小批注正文有时本身就能表达其主题或分类，不需要为了分类而强制添加标签。
- 批注类型只用于区分小批注、章节批注和大批注的业务性质，不是用户自定义分类。
- 正文、标签属于批注实体；原文位置及该位置的显示样式属于绑定关系。

### 2.2 小批注

用途：围绕具体原文片段记录想法、线索、疑点、人物关系等。

规则：

- 一条小批注只有一份独立正文和一组标签。
- 一条小批注可以绑定同一本书内的多个原文位置，位置可以分布在不同章节。
- 每个绑定位置必须完整位于单个章节内；普通跨章选文、复制不能因此受到限制。
- 多个绑定位置允许交叠、嵌套。
- 给已有小批注追加位置，是给同一个批注实体增加绑定，不得复制出另一条批注。
- 不允许产生没有正文的纯高亮。高亮/下划线只是有效小批注绑定位置的视觉提示，不是独立内容类型。
- 点击原文的交叠绑定区域时，按这些位置的集合并集处理，展示该并集关联的全部批注，规则见第 6 节。
- 无绑定的小批注仍然存在，可在完整批注管理界面检索和编辑，不得因为没有绑定而消失。

### 2.3 章节批注

用途：记录某一章的整体理解、总结、评论或分析。

规则：

- 一条章节批注只有正文和标签，没有标题。
- 可以没有绑定，也可以绑定一个章节。
- 同一章节允许存在多条独立章节批注。
- 新建入口位于阅读区域鼠标右键菜单。
- 右键不要求选中文字；根据鼠标点击位置确定所属章节。
- 新建时自动绑定鼠标右键所在章节。
- 后续换绑通过章节批注自己的编辑/管理界面选择目标章节，不在阅读正文中选中文字或选择绑定位置。
- 无绑定的章节批注仍可在完整批注管理界面检索和编辑。

### 2.4 大批注

用途：针对连续多个章节进行较长篇幅的整理、分析或写作。

规则：

- 一条大批注只有正文和标签，没有标题。
- 可以没有绑定，也可以绑定一个连续章节范围。
- 范围由起始章节和结束章节确定。
- 当前规则不支持离散章节多选，也不支持从范围中单独剔除中间章节。
- 新建入口位于阅读区域鼠标右键菜单。
- 新建时自动绑定鼠标右键所在章节，初始起始章节和结束章节均为该章。
- 后续调整范围，在大批注自己的编辑界面中选择起始章和结束章；不在阅读正文中通过选文完成。
- 参考资料区自动展示当前大批注绑定范围内的小批注和章节批注。范围改变后，参考资料应按新范围刷新。
- 参考资料的当前确定用途是查看和参考：点击资料查看详情，不自动修改原批注。
- 大批注可在阅读界面的当前章节批注展示面板中查询，按绑定的连续章节范围是否覆盖当前章节判断是否属于当前章节。
- 无绑定的大批注仍可在完整批注管理界面检索和编辑。

## 3. 绑定、状态与删除规则

批注正文与绑定关系必须分开处理。

- 删除批注：删除批注实体及其相关绑定位置。
- 解除绑定：只取消选定位置或整个章节/范围绑定，批注正文和标签仍然保留。
- 不得将位置失效误报为批注正文丢失。
- 有效、待处理、失效、主动解绑等位置状态应有用户能理解的区别。
- 自动恢复位置与用户主动换绑是不同操作；自动匹配和手动绑定不互相排斥。具体恢复和换绑入口属于完整管理流程，阅读界面不承担复杂位置管理。

小批注的手动换绑流程：

- 先解除需要替换的旧位置绑定关系。
- 再回到小说阅读界面，选中新的目标原文，通过“添加到已有小批注”选择原批注并建立新位置绑定。
- 每次建立绑定时，更新该绑定对应的章节信息。
- 自动位置匹配与用户主动手动绑定并不冲突，不得以“存在手动绑定”为由禁止后续自动匹配。

章节批注和大批注的换绑方式不同：必须分别进入各自的编辑页面，通过章节选择控件重新选择目标章节/连续范围；不能在阅读正文中选中文字来改变它们的绑定。

## 4. 阅读界面总体信息架构

### 4.1 独立右侧快捷工具栏

采用方案 A：右侧快捷工具栏独立于阅读工作区，常驻在阅读界面最右侧，不并入最右侧内容面板。工具栏宽度较窄，主要放置常用入口。

目前确定的入口：

1. 目录
2. 当前章节批注展示
3. 阅读界面设置

目录负责章节导航；当前章节批注入口打开第 5 节定义的批注展示面板；阅读设置用于字体、字号、行距、正文宽度等阅读参数。工具栏只承担入口职责，不承载完整内容管理。

阅读工作区的宽度计算应扣除独立工具栏的宽度。工具栏不计入章节批注或大批注工作区的分栏比例。

### 4.2 阅读工作区布局

已明确的布局方向：

- 正常阅读：正文占据主要工作区，右侧快捷工具栏独立常驻。
- 新建小批注：编辑面板在阅读区域底部居中显示；相较当前设计需要加宽。
- 新建章节批注：正文在左、编辑面板在右；初步按阅读工作区约三分之二与三分之一分配。
- 新建大批注：正文在左、参考资料区在中、编辑区在右；初步按阅读工作区三等分。
- 当前章节批注展示：正文在左、批注面板在右；初步按阅读工作区约三分之二与三分之一分配。

以上比例是当前讨论形成的布局方向。实际实现应考虑窗口尺寸和最小可用宽度；是否允许用户拖动调整分隔线、各状态精确宽度和小窗口降级方式尚未确定。

### 4.3 普通面板与新建编辑区

阅读界面中的快速新建面板与完整二次编辑/管理界面职责不同：

- 新建面板只保留完成当前创建所必需的信息和操作。
- 不在新建面板中塞入完整绑定管理、解绑、删除、恢复等复杂功能。
- 统一批注管理工作区提供三类批注的完整详情与必要编辑/绑定管理；**阅读界面右侧面板允许对章节批注和大批注触发二次编辑**，复用各自的新建工作区。小批注暂不允许从该右侧面板触发二次编辑。
- 阅读界面以「记」与当前上下文「查」为主，不因补充二次编辑入口而变成全书批量管理页面。

## 5. 阅读界面入口与操作流程

### 5.1 选中文字后的弹窗菜单：横向排列

选中文字后出现的原文操作菜单采用横向排列。当前确定的主要入口：

- 新建小批注
- 添加到已有小批注
- 复制

新建小批注和追加到已有小批注均从选文菜单进入。普通复制继续可用。

添加到已有小批注必须选择已有实体并为其增加当前位置绑定，不得创建重复实体。选择器的具体搜索、摘要字段和分页交互仍需细化。

### 5.2 阅读区域鼠标右键菜单：纵向排列

鼠标右键点击阅读正文任意位置时，弹出的菜单采用纵向排列。当前确定的入口：

- 新建章节批注
- 新建大批注

右键不要求选中文字。程序根据右键坐标确定所在章节，并按第 2 节规则初始化绑定。

### 5.3 小批注快速新建

- 通过选中文字后的横向菜单触发。
- 编辑面板显示在阅读区域底部并居中，宽度比当前设计更大。
- 显示当前选中的原文摘录，正文输入区占主要空间。
- 提供标签输入/选择。
- 不显示标题输入、内部分类、复杂绑定管理或删除功能。
- 保存后创建小批注实体及对应原文位置绑定。
- 不提供独立“仅高亮”操作。

具体标签选择控件、快速保存反馈和取消时的数据保护方式尚待后续讨论。

### 5.4 章节批注快速新建

- 从阅读正文右键菜单触发。
- 自动取得鼠标所在章节并绑定该章节。
- 阅读正文在左，右侧新建编辑面板在右，当前布局方向约为 2/3 + 1/3。
- 新建面板提供章节信息、正文输入和标签。
- 不显示标题输入、内部分类、复杂绑定管理或删除功能。
- 章节批注允许不绑定章节；是否允许空正文实体及保存校验规则尚未讨论，不应自行推断。
- 从阅读界面右侧面板二次编辑已有章节批注时，使用与新建相同的左右工作区布局；载入原实体并更新，不另建实体。

### 5.5 大批注快速新建

- 从阅读正文右键菜单触发。
- 自动取得鼠标所在章节，初始起始章和结束章均为当前章节。
- 工作区从左至右为阅读正文、参考资料、正文编辑区，当前布局方向约为三等分。
- 参考资料自动查询当前连续章节范围内的小批注和章节批注。
- 点击参考资料查看原批注详情；查看行为不修改原批注。
- 大批注编辑区提供范围信息、正文输入和标签，不显示标题或内部分类。
- 调整范围后，参考资料随新范围刷新。
- 大批注可在阅读界面的当前章节批注展示面板中查询，按绑定的连续章节范围是否覆盖当前章节判断是否属于当前章节。

从阅读界面右侧面板二次编辑已有大批注时，使用与新建相同的正文 + 参考资料 + 编辑区三栏布局；参考资料区保留，更新原实体而不是新建。**统一管理工作区中的大批注详情/编辑不提供参考资料区。**

章节选择器必须考虑几千章目录的使用规模，不能默认采用一次性渲染几千个选项的普通长下拉框。搜索方式、范围预览、键盘操作和精确加载策略尚待后续设计。

## 6. 原文绑定标识、交叠处理与详情展示

### 6.1 正常阅读状态下的绑定标识

取消复杂的高亮颜色和划线工具。保留一种统一的绑定提示样式：

- 有有效小批注绑定的原文，在文字下方显示细密虚线或点线。
- 该虚线/点线是“此处有关联批注”的提示，不是背景色块，不表示当前正在查看该批注。
- 不同批注不使用多种高亮颜色区分。
- 该视觉提示只针对有效绑定位置；待处理、失效和主动解绑状态的视觉细节仍需设计。

用户提供的第二张截图展示了文字下方细密虚线/点线的参考效果。截图仅作为视觉参考，不代表最终 CSS 或像素参数已经确定。

### 6.2 从批注面板主动定位原文

- 用户从右侧批注展示面板的某个位置条目跳转到原文后，该位置对应的原文显示临时高亮，以区别于普通状态下的虚线/点线提示。
- 临时高亮是导航定位反馈，不创建新绑定、不改变原批注、不改变绑定状态。
- 临时高亮与正常绑定虚线的具体叠加、持续时长和清除条件尚未确定。

### 6.3 交叠绑定按集合并集处理

当多个小批注绑定位置交叠或嵌套时：

- 正常阅读时，重叠范围作为统一的绑定提示区域呈现，不通过多种颜色区分各批注。
- 对于相互交叠的绑定范围，按集合并集处理。若 A 与 B 交叠、B 与 C 交叠，则 A、B、C 属于同一连续并集。
- 点击该并集范围内任意文字，展示与该并集关联的全部批注。
- 每条批注仍是独立实体；不得把多个正文合并成一条新批注。
- 同一批注即使有多个位置，也不得因多个位置命中而重复展示同一批注实体。

### 6.4 交叠位置的浮动详情框

点击交叠高亮并集后，采用方案 A：在点击位置附近弹出浮动详情框，不占用右侧批注面板，也不改变阅读工作区布局。

每条批注默认展示：

- 对应当前命中位置的原文摘要；
- 批注正文摘要；
- 标签（具体是否常驻展示可在后续视觉细化时确认）。

不显示标题，因为三类批注均无标题。

用户可以点击单条批注展开查看完整正文。多条批注应分别展示，不能混为一条。

关闭规则：

- 点击浮动框外部区域：关闭。
- 按 Esc：关闭。
- 浮动框打开期间，点击另一个高亮位置也视为点击外部区域，先关闭当前浮动框；不直接更新当前批注集合。用户关闭后再次点击另一个高亮位置，才打开对应详情框。

浮动框的边缘避让、最大高度、内部滚动和精确锚点定位方式仍需实现设计确认。

## 7. 阅读界面右侧批注展示面板（当前章节上下文）

### 7.1 展示范围与类型切换

右侧面板支持**小批注、章节批注、大批注**，顶部以三类切换控件分开浏览，不混排；这是对旧版「只展示小批注、章节批注」的明确修订。

- 小批注：展示至少有一个有效绑定位置属于当前章节的批注实体；同一批注只列一次。
- 章节批注：展示绑定当前章节的章节批注。
- 大批注：展示绑定的连续章节范围覆盖当前章节的大批注。大批注不因范围跨多章而复制出多条实体。
- 无绑定批注不属于当前章节面板的查询结果，但在统一管理工作区保留。
- 切换类型不改变阅读位置；列表按需查询/分页，详情正文按需读取。每类滚动位置、排序、空状态尚待细化。

### 7.2 列表与详情

- 列表以正文摘要为主要识别内容，不出现标题；可展示标签和绑定摘要。
- 点击列表中的单条批注，在右侧面板中展开只读详情。
- 小批注的位置条目显示**章节名称 + 对应原文摘要**；同章多处也分别显示，不以「位置 1、2」替代。
- 章节批注显示其章节名称，不虚构选文锚点。
- 大批注显示起止章节及正文、标签；**不提供大批注原文预览/跳转**。

### 7.3 阅读面板中的二次编辑

- **小批注**：在右侧面板中只查询、查看和定位，暂不提供二次编辑入口。
- **章节批注**：右侧详情允许触发二次编辑，复用阅读界面的「正文左 + 编辑区右」新建布局，载入并更新原批注。
- **大批注**：右侧详情允许触发二次编辑，复用阅读界面的「正文左 + 参考资料中 + 编辑区右」新建布局，载入并更新原批注；参考资料依旧按当前连续范围查询。
- 二次编辑不改变批注类型、绑定模型或删除/解绑语义。

### 7.4 阅读界面中的真正定位与「返回原处」

- 点击右侧面板内小批注的某条位置条目，**真正跳转阅读正文**到对应原文，临时高亮该处；面板保持打开并保留当前详情。
- 章节批注可在阅读界面定位到对应章节；章内视觉细节尚待明确。
- 跨章节跳转继续复用阅读器已有的「返回原处」机制，不另建批注专用返回栈。
- 以上是**阅读界面右侧面板**的操作，与第 8.4 节统一管理工作区中的「单章原文预览弹窗」不同；后者不改变阅读位置。

## 8. 统一批注管理工作区（阅读界面之外）

### 8.1 范围、导航与三栏结构

- 一个统一的管理工作区，**一次只管理左侧当前选中的一本书**，但可通过**左侧顶部的书籍切换控件**切换书籍；不在同一列表混合整个书库的批注。
- **左侧**：顶部切换书籍；下方依次提供「小批注、章节批注、大批注、局部标签」入口，允许未来增加新的管理对象。**不提供全局标签管理入口**，也不采用先前提议的「全部 / 小批注 / 章节批注 / 大批注」顶部混合标签页。
- **中间**：展示当前书籍、当前导航项对应的批注列表或局部标签列表；支持选择一项后联动右侧。
- **右侧**：展示所选批注的完整详情和必要编辑、绑定管理。三种批注按各自业务类型改变右侧结构。
- 选择「局部标签」时，建议中间与右侧合并为宽幅列表式标签管理区域，不强行保留空的详情列。
- 书籍切换、数据为空/加载失败和面板之间保留状态的具体交互尚未定稿，不推断自动保存等行为。

### 8.2 中间批注列表

批注不设标题，以**正文摘要为主、标签和绑定信息为辅**；布局紧凑、可读且不臃肿。

| 列表类型 | 主信息 | 辅助信息 |
|---|---|---|
| 小批注 | 正文摘要 | 标签、绑定位置数量、涉及章节 |
| 章节批注 | 正文摘要 | 标签、绑定章节 |
| 大批注 | 正文摘要 | 标签、连续起止章节 |

无绑定批注仍在各自列表出现，辅助信息显示「未绑定」。列表按需加载，不一次读取全书所有正文；搜索字段、搜索范围、筛选、排序、批量操作、分页的具体交互仍未定稿。

### 8.3 右侧查看与编辑原则

- 默认**只读查看**；点击笔形编辑入口进入编辑状态，保存后返回查看状态。默认以正文为主，标签/章节/绑定为辅助信息。
- 不要求所有字段都用同一种编辑方式：短字段且空间够时原位置编辑；长篇正文在右侧原位置编辑并独立滚动；多个绑定、标签选择等较复杂操作采用居中弹窗。
- 小批注：顶部信息、正文、标签构成上方内容区，**其下边缘最多到达整个右侧详情区高度的约 2/3**，不是正文固定占 2/3；正文短则自然收缩，长则正文内部滚动。下方为绑定位置列表，使用剩余空间**独立滚动**；不限制默认显示的数量，不提供「查看全部」。
- 小批注位置列表逐条显示「章节名称 + 原文摘要」，可直接打开第 8.4 节的单章预览；复杂解绑/换绑通过居中管理弹窗处理，不在正常查看态堆砌按钮。
- 章节批注：按**章节信息 → 标签 → 正文**排列；正文使用可用空间，不强制 2/3 上限。编辑时可以通过章节选择控件/弹窗换绑。
- 大批注：按**章节范围 → 标签 → 正文**排列；正文占主要空间，可原位置编辑；范围修改经起止章节选择控件/弹窗；**不设参考资料区，也不设原文预览入口**。
- 三类批注的绑定变更仍遵守第 3 节：小批注新增绑定要返回阅读界面选文并「添加到已有小批注」，章节/大批注则在自身编辑界面选择章节/连续范围。

### 8.4 统一管理工作区中的「原文预览」（不是阅读跳转）

- **小批注和章节批注支持原文预览；大批注不支持**。
- 点击小批注的某条绑定位置或章节批注的绑定章节时，在**屏幕中央打开较大的原文预览弹窗**。
- 预览仅加载并显示**该位置所属的单个章节完整正文**，可在弹窗中上下滚动；不拼接相邻章节、不提供跨章连续阅读。
- 小批注：打开后自动滚动到所选原文锚点，并临时高亮该处；一个批注有多个位置时以点击的那一处为准。
- 章节批注：从章节开头展示，无选文高亮。
- 关闭预览回到原管理详情，**不修改主阅读器的阅读位置或阅读进度，不使用「返回原处」**。
- 阅读界面右侧面板内已确认的真实阅读跳转继续按第 7.4 节执行，不能混淆这两个入口。

## 9. 标签作用域与局部标签管理

### 9.1 全局与局部标签

- **全局标签**跨全部书籍可用，**局部标签**仅归属一本书；两类均可被小批注、章节批注和大批注选择，均为可选。
- 当前统一管理工作区**仅管理所选书籍的局部标签**。全局标签的独立管理界面、入口及跨书使用统计尚未确定，暂不纳入此次界面范围。
- 现有标签能力不自动等同于已经实现「全局/局部标签」持久作用域；实施前需评估现有 JSON 标签、身份、冲突、备份和迁移影响。

### 9.2 局部标签列表与操作

- 左侧点击「局部标签」后，中间和右侧合并为宽幅**列表式**管理区域，适合几十到几百个标签。
- 每行展示标签名称和使用它的批注数量，并提供编辑/删除入口；标签名称适合原位置编辑。颜色是否作为可编辑属性尚未定稿。
- **删除**：如有批注使用，明确提示影响数量并确认；只解除标签和相关批注之间的关联，不删除批注、正文、其他标签或原文绑定。
- **重命名且无冲突**：新名称统一同步到当前书籍使用该局部标签的所有三类批注；不要求逐条编辑，其他内容不变。
- **重命名与现有局部标签同名**：提示将执行合并及相关使用数量；确认后把源标签关联关系并入目标标签，重复使用关系去重，最后移除源标签。取消则不合并。
- 上述原子更新/回滚、关联数据兼容与数量统计需在开发阶段验证；此处是已确认的产品结果，不预先指定数据库表结构。

## 10. 统一视觉与交互风格

- 整体风格**简洁、轻量、圆润、尺寸适中、层次清晰、留白合理**；不使用冗长说明文字，不堆叠卡片边框或密集控件。
- 顶部操作与正文、标签、绑定信息的主次清晰，按钮和可点击图标有可辨认但不过分抢眼的反馈。
- 简单操作就地完成，复杂对象用居中弹窗；弹窗尺寸适当，长内容在弹窗内部滚动，不无限撑高窗口。
- 具体像素、圆角半径、颜色、可拖动分栏、最小宽度、超窄窗口降级均尚未定稿，不将示意草图当最终设计。
