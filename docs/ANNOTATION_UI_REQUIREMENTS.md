# 批注界面需求（当前精简版）

- 更新时间：2026-11-09
- 适用范围：Windows Electron 版 Koodo Reader，大型 TXT 阅读场景
- 文档定位：**当前两阶段的唯一有效批注 UI 开发范围**；旧版复杂 UI 方案不再作为开发依据
- 状态：用户说明已回退到正式界面改造前的版本。开始开发前仍需核对实际仓库代码、分支与工作区；本文不是代码已完成或已验收的证明

## 1. 当前目标与边界

这轮不做完整批注系统的界面重构。先把**小批注和章节批注的新建、当前章节批注查看**做好，再做**大批注新建及其参考资料查看**。按步骤开发，每完成一个步骤先由用户实际体验、调整满意后，再继续下一步；不要一次性开发整套界面。

**本轮不开发**：任何类型批注的二次编辑、标签输入及标签管理、统一批注管理界面、全书库/跨书籍批注查询、复杂搜索筛选排序、批量操作、引用关系、回收站、复杂草稿系统、独立的位置解绑/换绑管理 UI。后续可能重新讨论，不保留旧方案的详细页面设计。

“不开发”只针对本轮界面范围；**不得为了精简界面删除现有数据库字段、已有批注、绑定、标签数据、备份恢复或其他底层能力**。不改造小说存储方式：书籍仍在 Koodo 原书库，不建小说项目文件夹、原文副本或第二套数据库。

三种批注在本轮新建界面中**均不提供标题、标签、内部分类**，只编辑批注正文及所属章节/范围的必要信息。不要为界面需求额外建立标题或分类字段。

## 2. 必须遵守的分栏布局规则

> **重要：章节批注编辑面板、当前章节批注查询面板，以及后续大批注参考资料面板和大批注编辑面板，必须和小说正文处于同一个阅读工作区、同一布局层级，以并列区域分栏。绝对不能实现为悬浮在正文上方的弹窗、抽屉覆盖层或绝对定位遮罩。**

实现要点：

1. 阅读正文区和右侧面板是阅读工作区内参与正常宽度分配的**同层并列区域**（可用 flex/grid 等常规布局实现）；面板打开时，正文容器**真实缩窄**，而非被面板覆盖。
2. 不得通过 z-index、position: absolute/fixed 或纯视觉 transform，把章节批注编辑面板、章节批注查询面板、参考资料面板、大批注编辑面板悬浮覆盖在原文之上。
3. 右侧**固定窄工具栏**独立于阅读工作区，始终在最右侧；阅读区的 2/3、1/3 等宽度比例以**扣除工具栏后的可用宽度**为准。
4. 章节批注新建与当前章节批注查询采用**正文约 2/3 + 右侧面板约 1/3**。这两种右侧面板是不同工作状态，不要求同时显示。
5. 大批注新建采用**正文约 1/3 + 中间参考资料约 1/3 + 右侧编辑约 1/3**，三个区域必须同层并列，不能先做悬浮面板假装三栏。
6. 原文和面板均应有正常的独立内容承载与滚动空间；布局变化时尽量保持当前阅读位置，不打断大型 TXT 连续阅读。
7. **例外仅限小批注快速输入**：它继续采用已确认的阅读区底部居中弹出形式，不套用上述侧边分栏规则。选文工具菜单、右键菜单也属于临时操作菜单，不属于禁止的“侧面板悬浮”。

结构示意（不是像素设计稿）：

正常阅读：

```text
┌───────────────────────────────────────────┬──────┐
│                 小说正文                  │工具栏│
└───────────────────────────────────────────┴──────┘
```

章节批注新建 **或** 当前章节批注查询：

```text
┌──────────────────────────┬────────────────┬──────┐
│        小说正文          │ 编辑/查询面板  │工具栏│
│          约2/3           │      约1/3     │      │
└──────────────────────────┴────────────────┴──────┘
```

大批注新建（第二阶段）：

```text
┌────────────────┬────────────────┬────────────────┬──────┐
│    小说正文    │    参考资料    │    大批注编辑  │工具栏│
│      约1/3     │      约1/3     │      约1/3     │      │
└────────────────┴────────────────┴────────────────┴──────┘
```

以上图中的相邻区域在**同一空间层级**。不能把右边两个区域做成覆盖左边正文的浮层。

## 3. 第一阶段：小批注、章节批注与当前章节查看

**顺序固定：右侧工具栏 → 小批注新建 → 章节批注新建 → 当前章节批注查询面板。** 每项完成后先人工体验，再进入下一项。

### 3.1 右侧固定工具栏

- 位于阅读界面最右侧，宽度较窄，与阅读工作区分离。
- 常用入口：**目录、当前章节批注、阅读设置**。
- 现阶段只建设必要布局与入口，不因新增工具栏而扩建完整管理页面。
- 工具栏不能随着编辑/查询面板打开而被覆盖或移入面板内部。

### 3.2 小批注新建

- 选中文字后出现的操作菜单是**横向排列**，保留普通复制，并提供“新建小批注”入口。
- 小批注输入窗口位于**阅读区底部居中**，在现有体验基础上适当加宽。
- 输入窗口显示本次选中的原文摘录、批注正文输入框、保存和取消；**不显示标题、标签、颜色选择、解绑、删除、完整管理控件**。
- 保存时新建一条小批注，并绑定本次选中的原文位置；新建的每个位置必须属于单个章节。普通跨章选文和复制仍需正常工作。
- **没有正文的“仅高亮”不是独立新建入口。**
- 本轮不新增“添加到已有小批注”的选择/追加流程，也不开发小批注二次编辑；既有底层多位置能力不删除。

### 3.3 章节批注新建

- 在阅读正文区域**右键任意位置**，通过**纵向右键菜单**选择“新建章节批注”；无需点中文字像素，也无需先选中文字。
- 根据右键所在的章节确定绑定目标；即使当前页面同时可见多个章节，也应取右键所在章节。
- 采用第 2 节的**同层左右分栏**：正文约 2/3，右侧章节批注新建面板约 1/3。
- 编辑面板只提供当前章节信息、批注正文、保存和取消；**不提供标题、标签、解绑、删除或二次编辑控件**。
- 同一章允许新建多条独立章节批注；不因已经存在一条就阻止再建。

### 3.4 当前章节批注查询面板

- 通过右侧固定工具栏打开，采用**正文约 2/3 + 查询面板约 1/3**的同层并列布局，不能浮在正文上。
- 面板顶部通过一个**双向切换控件**切换“小批注 / 章节批注”，**分开展示，不上下混排**。
- **只显示小批注和章节批注，不显示大批注。**
- 只查询与**当前章节**有关的批注，不扩展为全书或跨书籍管理。
- 小批注每条以正文摘要为主要内容，位置须通过**章节名称 + 对应原文摘要**辨认；同一批注的多个位置不能只显示“位置1/2”等数字。
- 章节批注以正文内容和对应章节辨认。点击批注可查看完整正文；本轮**只读，不提供二次编辑**。
- 从小批注的位置条目点击定位时，真实跳转到该处原文；跨章节跳转复用已有目录跳转的**“返回原处”**功能，不新增第二套返回机制。
- 正常有效绑定的小批注原文使用文字下方的**细密虚线/点线**提示；从查询面板主动定位时，目标原文**临时高亮**，与普通提示区分。具体线型、持续时长等视觉参数留到实际开发体验时调整。
- 列表摘要按需查询，完整正文按需读取，不一次加载全书批注正文。

## 4. 第二阶段：大批注新建及参考资料查看

**必须在第一阶段“当前章节批注查询面板”完成并经体验调整后再开始。**

### 4.1 大批注新建

- 在阅读正文区域右键，通过**纵向菜单**选择“新建大批注”，按右键所在章节确定初始绑定。
- 初始**起始章节 = 结束章节 = 右键所在章节**。
- 支持在编辑界面调整起始章和结束章，绑定**一个连续章节范围**，不支持离散多选或排除中间章节。
- 直接采用第 2 节规定的**同层三栏**：正文在左、参考资料在中、编辑在右，固定工具栏始终独立在最右侧。
- 大批注新建只编辑**正文和连续章节范围**，提供保存/取消；没有标题、标签或二次编辑流程。

### 4.2 大批注参考资料区

- 参考资料区自动查询大批注**当前绑定范围内**的小批注和章节批注，不查询大批注本身。
- 点击参考资料查看批注详情，**只读**，不修改原批注。
- 起止章节范围发生变化，参考资料应随之更新。
- 优先复用第一阶段当前章节批注查询的摘要和详情能力，但两者查询范围不同：第一阶段是当前章节，第二阶段是连续章节范围。
- 不实现把参考资料插入正文、建立引用关系、跨书检索或复杂资料管理。

## 5. 当前保留的数据与性能约束

- 三类批注是独立实体，不存在小批注隶属章节批注、章节批注隶属大批注的数据父子关系。
- 小批注底层允许同书多个原文位置、跨章分布和位置交叠；章节批注允许零或一章绑定；大批注允许零或一个连续章节范围。**本轮新建 UI 只实现各自的新建绑定，不做复杂绑定管理。**
- 删除批注与解除绑定是不同概念；本轮 UI 不实现相应管理操作，但不能因此删除或破坏已有底层能力。
- 原文变化后的保守恢复、未绑定内容保留、备份恢复、已有数据均需受到保护。
- 章节选择不得一次渲染几千个选项；参考资料/批注查询按需加载，不能为了界面方便将大量完整正文一次载入内存。
- 复用现有目录、阅读位置、选文菜单、受控批注服务和“返回原处”能力。涉及实现变更时先检查实际代码，不以旧原型或旧测试结果当作本轮 UI 已完成。

## 6. 开发与验收原则

- **先小步开发、人工验收，再继续下一项**；未经讨论不要增加额外功能或“顺便”重构整个批注系统。
- 重点验收侧边面板的**真实同层分栏**：打开时正文宽度实际收缩，面板与正文彼此并列；滚动、鼠标命中和正文阅读均不被浮层遮挡。此项是**必须通过的验收条件**。
- 验证选文横向菜单与正文右键纵向菜单不能混淆；验证右键位置跨章时章节绑定正确。
- 验证查询面板仅有小批注/章节批注、能按章节查看与定位，跨章节跳转能够返回原处。
- 验证大批注三栏同层排列、连续章节范围和参考资料随范围更新。
- 保存失败不能误报成功或丢失已输入内容；详细草稿策略不在本轮扩展。
- 记录“已设计 / 已实现 / 自动验证 / 用户实测 / 待验证”状态，不能把文档视为代码完成证明。
