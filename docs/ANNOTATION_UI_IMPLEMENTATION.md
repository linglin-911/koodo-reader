## UI-2 阅读快速记录

- 两库开始时工作区干净，fetch 后 Koodo `e68b0402` 领先远端3提交，Kookit `5c4928d` 与远端一致；保持当前分支。
- 独立48px右侧入口栏及共享宽度计算；选文横向三入口、TXT正文纵向右键菜单，按坐标映射点击章。
- 小批注底部加宽编辑、章节批注左右布局、大批注三栏布局；正文与可选全局/本书标签通过稳定ID写入。目录只挂载可见的最多12个按钮。
- 大批注参考区自动按完整连续范围分页查询小/章批注；详情独立只读，不替换大批注草稿。新的小批注禁止空正文，历史空小批注、标题和样式未清理。
- Kookit源码新增点击章映射、统一点线提示，经 `yarn.cmd build:desktop` 同步桌面产物；保留源文字节点与复制路径。
- 交叠点击通过受控 `overlap` 查询使用区间传递并集、实体去重及分页，不以挂载片段替代完整绑定；逐条详情按需加载，外点/Esc关闭，当前浮框打开时另一位置点击只关闭。

验证：`yarn.cmd typecheck`、Vitest16项、批注诊断2项、隔离原生SQLite21项通过；新增 `test/annotation-quick.electron.cjs` 12项通过，`rendererErrors=[]`、`userDatabaseOpened=false`、`normalCompiledEngine=true`。覆盖真实连续TXT合成多章同屏坐标、同名双作用域、故障回滚/草稿保留、追加不复制、完整范围参考、传递/嵌套并集分页、点线及文字保留、浮框关闭、7700章控件有界和共享宽度。截图已检查小新建与大三栏。原有 `annotation-reader` 旧菜单视觉断言已被此专项覆盖，不能作为新UI验收。
