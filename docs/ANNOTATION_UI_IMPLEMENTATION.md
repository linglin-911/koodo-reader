## UI-4 统一批注管理

Electron的批注入口直接进入单书三栏管理；左侧书籍切换及小/章/大/局部标签导航，中间每页50条摘要，右侧默认只读。管理小批注上方正文/标签区自然收缩、最大2/3，位置列表使用剩余空间独立滚动且最多挂载14行；并非只提供14个位置。标签复杂选择居中弹窗，正文原位保存后回只读；绑定管理独立弹窗，解除关系不删除实体。历史标题不显示、不被正文保存覆盖。管理大批注没有阅读参考区或原文预览入口。

新增列表绑定数量/最多3个涉及章名的摘要元数据，不读取列表正文全文。局部标签导航的管理功能由UI-6接入；小/章预览由UI-5接入。保留旧web界面源码，但Electron不再进入混合全书笔记/高亮页。

`annotation-management.electron.cjs` 23项隔离测试通过（含UI-2/3共17项回归），覆盖单书隔离、四项导航、只读详情、原位编辑/回查看、隐藏历史标题保留、解绑正文保留、大批注无参考/预览和书籍切换清理详情；rendererErrors为空，未打开正式库。类型检查通过。正式实书与全窗口视觉验收仍待。


## UI-5 单章原文预览

管理小批注点击具体位置、章节批注点击绑定章节打开居中预览；只含一个完整章节，不拼相邻章。小批注按所点绑定定位/高亮；章节批注章首打开且无选文高亮。独立源会话和实例不写主阅读位置或Return，关闭/Esc释放iframe、观察器和源会话。连续块读取复用已有TXT窗口预算，原文不进入整章字符串缓存。

测试发现并修复Kookit的全局 `#page-area` 文档查找：`GeneralRender.getDocument/getIframe` 现在优先所属实例的element，防止预览误用主阅读文档；已正常 `build:desktop` 同步产物。单章预览把展示序号重排为0，保留原chapterId/字节/文本坐标，所有读取委托到原章，持久索引禁止写入。

`annotation-preview.electron.cjs` 27项隔离测试通过（含前阶段23项）；新增单章边界、所点位置高亮、iframe Escape、主阅读/Return零变化、章首无高亮、多MB巨章DOM有界及销毁释放。rendererErrors为空，正式库未打开；预览截图已检查。类型检查通过。正式实书/非TXT预览及完整人工验收未宣称通过。


## UI-6 本书局部标签管理

局部标签导航将中/右合并为宽列表，每页50项，显示标签名和跨三类独立实体的使用数量。支持新建、名称原位编辑、删除和同名合并。删除/合并复用UI-1的首次检查和带版本确认协议，在弹窗明确显示独立受影响数量；取消不写入。这里只管理当前书籍局部标签，无全局管理入口。错误保留输入和确认上下文，不自动覆盖并发修改。
